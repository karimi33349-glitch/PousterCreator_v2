# پوستر ساز جلسات فقهی — نسخه ۲

این نسخه رابط کاربری را مطابق تصویر ارسالی توسعه می‌دهد.

## امکانات

### ۱. پیش‌نمایش پوستر
پس از ساخت پوستر، تصویر آن در پنل پیش‌نمایش نمایش داده می‌شود.

### ۲. پوسترهای ذخیره‌شده
پوشه `output` در شروع برنامه بررسی می‌شود و تمام فایل‌های
`poster_*.jpg` در گالری نمایش داده می‌شوند.

با کلیک روی هر بندانگشتی، همان پوستر در پیش‌نمایش اصلی باز می‌شود.

### ۳. انتخاب عکس
انتخاب عکس با `FilePicker` و `with_data=True` انجام می‌شود تا در وب هم
به مسیر فیزیکی فایل وابسته نباشد.

### ۴. ساخت و ذخیره خودکار
هر پوستر جدید به شکل زیر ذخیره می‌شود:

`output/poster_1.jpg`
`output/poster_2.jpg`
...

### ۵. ذخیره / دانلود
پوستر فعلی را می‌توان با نام دلخواه در پنجره ذخیره سیستم ذخیره کرد.
در وب، همین قابلیت به دانلود فایل تبدیل می‌شود.

### ۶. اشتراک‌گذاری
روی ویندوز/اندروید از سرویس Share استفاده می‌شود.
در وب، چون محدودیت‌های مرورگر برای share sheet وجود دارد، مسیر دانلود
به‌عنوان fallback استفاده می‌شود.

## فایل‌های لازم

دو فایل زیر باید داخل `assets` باشند:

- `template.jpg`
- `calibrib.ttf`

## اجرا

```bash
pip install -r requirements.txt
flet run main.py
```

وب:

```bash
flet run main.py --web
```

## ساخت APK

Workflow داخل:

`.github/workflows/apk-build.yml`

قرار دارد.

نکته: گالری دائمی فایل‌ها روی ویندوز و اندروید بر اساس پوشه `output`
است. در حالت وب، فایل محلی مرورگر مانند یک پوشه دائمی کنار برنامه در دسترس
نیست؛ برای خروجی وب از دانلود فایل استفاده می‌شود.
